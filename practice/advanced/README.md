## 📋 Prerequisites

Ensure you have the **GitHub Copilot Chat** extension and access to:
- **GitHub Copilot Pro, Pro+, Business, or Enterprise** subscription
- **VS Code 1.100+** (or VS Code Insiders for preview features)
- **Agent mode** enabled (mode dropdown in Copilot Chat panel)
- Some modules (14, 15) require **Copilot Pro+** or **Enterprise** for cloud agent and Spaces features

## 🚀 Getting Started

Work through modules in order, or jump to specific topics:
- **Foundation**: Start with 01-05 for core advanced skills
- **2024 Features**: Explore 06-10 for multi-file editing, models, extensions, prompt files, vision
- **2025 Features**: Explore 11-15 for multi-agent, custom agents, skills, cloud agents, spaces
- **Reading First**: Read corresponding materials before hands-on exercises
